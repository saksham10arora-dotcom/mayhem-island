# Mayhem Island

A floating island you drive a toy car around, with real physics. Smash the name wall, bowl, topple dominoes, jump the hoop and press the button you were told not to.

Live: https://saksham.digital/mayhem-island/

WASD or arrows to drive, Shift to boost, Space for handbrake, R to flip the car back, T to rebuild everything. One HTML file, three.js r128 and cannon.js 0.6.2.
